# tirol-rsya-a: правки для модерации РСЯ (ТЗ «ЩИТ»)

**Дата:** 28.09.2026
**Адрес:** https://land.tirolab.ru/rsya/tirol/a/

Флаг `export const MODERATION = true;` в `src/hero.js`. При нём не рендерятся:

- первый экран: заголовок «Ищу 4-х женщин…», подзаголовок, блоки «Какие условия?» и «Что делать?»,
  список подарков «Регистрируйтесь прямо сейчас и заберите подарки». Остаются плашка с датой,
  строка «Бесплатная онлайн-программа…» и кнопка «Зарегистрироваться»;
- второй экран: «с врачом эндокринологом-гинекологом» и
  «и избавления от симптомов при АИТ и Гипер/Гипотиреозе - БЕЗ ЛЕКАРСТВ»;
- блоки «Позвольте представиться», «Более 25 лет я помогаю женщинам…»,
  «Этот бесплатный курс даст возможность…»;
- нижний блок регистрации: заголовок, список подарков и макет с подарками. Форма GetCourse остаётся.

Не тронуты (в ТЗ не отмечены): «Получите ДВА ПОДАРКА» на втором экране,
блок отзывов с заголовком «…оздоровление щитовидки БЕЗ ЛЕКАРСТВ», футер.

Подгонка вёрстки под оставшееся: правила `.is-moderation` в конце `src/styles.css`.

## Откат

Одной командой из корня монорепо (автодеплой по пушу в `main`):

    git revert --no-edit <sha коммита с правками> && git push origin main

Либо поставить `MODERATION = false` и запушить: разметка и стили вернутся к полной версии.
